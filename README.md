# Ragatoni

## Project description

Ragatoni is a demo for retrieval-augmented generation. It lets people play around and experiment with different types of RAG. This branch is a fresh start for building that demo.

## Project dependencies

- Python 3.10+
- Node.js and npm
- Docker (Postgres with pgvector; optional Adminer for local DB inspection)

Backend packages are in `backend/requirements.txt` (`openai`, `psycopg`, FastAPI, and related). The frontend uses Vite and React.
